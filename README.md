
# Hangman Game

## About
Hangman is a simple word-guessing game developed using Python.
The player tries to guess a hidden word one letter at a time
before running out of attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Displays correctly guessed letters
- Tracks incorrect guesses
- Shows win or lose messages
- Simple and beginner-friendly gameplay

## Technologies Used
- Python 3
- Random module

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python Hangman.py

## How to Play
1. Run the program.
2. Guess one letter at a time.
3. Correct guesses reveal letters in the word.
4. Incorrect guesses use up your attempts.
5. Guess the complete word to win!
